# Sparklog

记录灵感的 Windows 桌面应用：自由摆放的气泡画布 + 一键切换的思维导图视图。
- 支持网状结构、专区（独立子画布）、笔记 / 任务 / 附件 / 图片

## 开发

```bash
npm install          # 安装依赖
npm run dev          # 开发模式（Electron + Vite HMR）
npm run build        # 构建到 out/
npm start            # 预览构建产物
npm run typecheck    # TypeScript 类型检查
```

## 测试

```bash
npm test          # 单元 + 逻辑集成（Vitest）
npm run test:perf # 性能基准（500 气泡场景，硬性阈值）
npm run test:e2e  # 端到端（Playwright + Electron 真机窗口）
npm run dist      # 打包安装包（electron-builder）
```

## 架构

```
src/main        Electron 主进程：窗口、菜单、文件 IO、最近打开、导出落盘
src/preload     contextBridge 白名单 API（渲染层不接触 Node）
src/shared      主/渲染共用：数据模型、文件编解码、常量、IPC 契约
src/renderer    渲染层：React + SVG 画布、Zustand 状态、纯函数 logic/
```

**分层纪律**：磁盘只在 `main/`，算法只在 `logic/`（纯函数、可单测、无 React），组件只负责连接状态与交互。

### 网状结构（D1 / D7）

- 建立第二条连接的方式：**Alt + 拖拽气泡到目标气泡上松手**（或右键「添加连接」）。
- **方向键**：左＝主父（第一个父），右＝第一个子，上/下＝同父兄弟。

### 删除语义（D2 / D3 / D4）

- `Delete`：**只删当前气泡**，其子气泡原地升级为新的主气泡，弹窗都不弹。
- `Shift+Delete`：删自身 + **独有后代**（只有经它才能到达的后代），必须二次确认；仍被其它父节点引用的气泡只断连、保留。

### 视图切换（D11）

- **连线**：气泡视图是直线（拖动时随两点距离实时伸缩），思维导图视图是导图风格曲线。
- **默认半径随层级递减**：每下一级 ×0.88（最低 0.55 倍）。滚轮调过重要程度或设置过样式的气泡不受此缩放影响。
- **编辑态**：原文字层完全不渲染，只剩编辑层与光标，不会出现重影。
- **拖拽物理**：拖动气泡时被拖对象跟手，相连的父子通过弹簧被带动，靠得太近的气泡互相排斥；松手后有惯性衰减直到静止，再一次性写入文档与撤销栈。
- **空白处滚轮 = 缩放画布**（悬停气泡的滚轮仍然只调该气泡的重要程度，Ctrl+滚轮同样缩放）。
- 工具栏（左侧）分段按钮：气泡视图 ⇄ 思维导图。
- 气泡视图使用并保存用户手动摆放的 `bubblePos`；**思维导图坐标实时计算、不落盘**，切换回来位置绝不丢失。
- 思维导图以每个主气泡为根自动布局，多父节点**只在其主父那棵树里出现一次**，其它父的连线画成跨树虚线回边。
- **导图视图内拖拽只作临时调整**：松手后不写入文档，重新布局或切换视图即复位。

### 拖拽网络与建立连接（D34 / D35）

- 拖动任一气泡时，**所有直接或间接相连的气泡**都会一起运动（整张网络跟着走），连线全程保持相连。
- 松手后惯性衰减到位才写入文档，一次拖动只产生一条撤销记录。
- 建立连接有两种方式（统一叫「建立连接」）：
  1. 右键气泡 A →「建立连接」→ 再点气泡 B；
  2. 按住 `Ctrl` 连续点击两个气泡（先点子气泡，再点父气泡）。
- 连接后的长度固定为建立时的初始距离，并保持不变（写入 `linkLength`）。
- 拖拽时**只有被按住的那一个气跟手**，其余（含折叠隐藏的后代）都是自由刚体：由弹簧与斥力带动并保留惯性，松手后整张网络一起滑行到共同静止（D36）。
- 同一父节点下的子气泡连线**默认等长**（父半径 + 子半径 + 默认间隙）；子节点过多放不下时，该父节点下所有子连线自动一起伸长，密度回落后自动恢复默认（手动固定过的除外）。
- 斥力覆盖**当前层级全部气泡**，不区分主父归属，任意两组气泡之间也不会重叠。
- `Ctrl + 左键拖拽` 单个气泡 = **调长度模式**：父级固定不动，该父子连线长度改为你拖出的距离，其它连线长度不变；重叠时其它气泡仍会被斥力弹开，松手即定稿（D38）。
- 折叠/展开按钮渲染在气泡自身的变换体系内，锚定连线发出点，随拖拽、滑行、缩放同步移动（D37）。

### 折叠与插入对象（D26 / D27 / D28）

- 有子气泡的父节点在连线发出处有一个圆形按钮：点一下折叠全部后代（按钮显示被隐藏的数量），再点展开。折叠状态写入文件。
- 笔记 / 任务 / 附件 / 图片插入在**鼠标右键点击处**。
- 附着在气泡上的对象默认折叠成**简笔小图标**排在气泡角上，点图标展开为卡片，卡片标题栏的 `⌃` 可再收起。
- 卡片可拖动，拖动后自动钉住（不再跟随气泡）；拖动时屏幕位移与鼠标 1:1，不随画布缩放放大或缩小（D39）。
- 附着在气泡上的对象绑定宿主坐标系，拖拽/物理运动/惯性滑行/缩放时与气泡保持相对位置，不脱离、不滞后（D41）。
- 任务卡支持**多行条目**，每行独立勾选；点「＋ 新建一行」或在行末按 Enter 新增，空行按 Backspace 删除。

### 专区（D13）

- 专区是独立子画布：自己的坐标系、自己的气泡、自己的视口记忆，可嵌套。
- 双击专区卡片进入，专区内双击空白处退回；面包屑可跳层。
- 把气泡拖到专区卡片上松手即移入该专区。

## 文件格式

`.insp` 是 UTF-8 JSON，顶层含 `fileVersion`、`viewMode`、`theme`、`rootViewport`，以及三个扁平池：`nodes` / `zones` / `inserts`。
节点通过 `parentIds` 与 `zoneId` 表达关系，边不单独存储（由 `parentIds` 推导）。
写入采用「临时文件 + rename」的原子替换，读取时校验版本、剪除失效引用、修复成环连接。

## 已知限制

- 撤销为**操作粒度**，不做逐字符撤销。
- 不做云同步、自动保存、深色模式、多语言。
- 安装包未做代码签名（无证书），Windows 可能提示未知发布者。
